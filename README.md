# Ammar Portfolio

Personlig portfolio byggd med HTML, CSS och JavaScript.

## Struktur

- `index.html` – innehåll och struktur
- `style.css` – design och responsiv layout
- `script.js` – mobilmeny, scroll-animationer och automatiskt årtal

## Starta projektet

Öppna projektmappen i VS Code och kör gärna med tillägget **Live Server**.

Alternativt kan du öppna `index.html` direkt i webbläsaren.

## Innan publicering

1. Byt `YOUR_EMAIL@example.com` i `index.html` till din riktiga e-postadress.
2. Byt LinkedIn-länken i `index.html` till din riktiga profil.
3. Kontrollera att GitHub-länkarna är rätt.
4. Anpassa text och projektbeskrivningar vid behov.
5. Lägg gärna till en profilbild i **Om mig** och en projektskärmdump per projekt.
6. Testa sidan på mobil, surfplatta och dator.
7. När sidan är klar kan den publiceras via exempelvis Vercel, Netlify eller GitHub Pages.
